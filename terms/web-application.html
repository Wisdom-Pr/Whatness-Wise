Web application

Computer Science

A web application is a software system that provides interactive functionality by processing user inputs on a remote server and delivering the resulting interface through a web browser.

Category
Software application
Identity
A client-server software system
Mechanism
executing logic via a remote server while rendering the user interface through a web browser
Resolved
The standard definition fails to distinguish web applications from static websites, which also run in a browser but lack interactive server-side state processing.

Usually defined as: A program that runs in a web browser.
