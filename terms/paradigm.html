Paradigm

Research Methods

Paradigm is a set of shared assumptions, concepts, and practices that defines the boundaries of legitimate inquiry and problem-solving within an intellectual community.

Category
Conceptual framework
Identity
A set of shared assumptions, concepts, values, and practices
Mechanism
defining the boundaries of legitimate inquiry and problem-solving within a scientific or intellectual community
Resolved
The standard definition is too broad, as it fails to distinguish a paradigm from a mere 'example' or 'model' used in everyday speech.

Usually defined as: A typical example or pattern of something; a model.
