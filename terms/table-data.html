Table (data)

Mathematics / Statistics
Also: table

A table is a structured data format that organizes information into a grid of labeled columns and distinct rows to allow for the systematic comparison and retrieval of related values.

Category
Data structure
Identity
A two-dimensional arrangement of related information
Mechanism
Organizing discrete values into intersecting rows and columns to enable systematic comparison and retrieval
Resolved
The standard definition fails to distinguish a table from a spreadsheet or a database view, and it omits the structural requirement of defined fields (columns) and records (rows).

Usually defined as: A set of facts or figures displayed in rows and columns.
