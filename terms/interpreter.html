Interpreter

Computer Science

An interpreter is a software system that executes high-level source code directly by parsing and performing each instruction sequentially at runtime.

Category
Software system
Identity
A program that executes source code directly without requiring a prior compilation stage.
Mechanism
Translating and executing high-level instructions sequentially at runtime.
Resolved
The standard definition often conflates the interpreter with the compiler by focusing on 'translation' rather than the direct execution of source code.

Usually defined as: A program that translates high-level code into machine language line-by-line during execution.
