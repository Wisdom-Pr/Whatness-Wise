Speed

Physics

Speed is a scalar quantity that measures how much distance an object covers in a given time.

CategoryA scalar quantity
IdentityDistance an object covers
MechanismMeasured against a given time
Resolved"How fast" was self-synonym circularity; "in a given time" was added since the original dropped the time half of the ratio
