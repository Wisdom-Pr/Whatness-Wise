Simultaneous equations

Mathematics

Simultaneous equations are a set of equations with the same unknowns that are solved together for the values that satisfy every equation at the same time.

Category
A set of equations
Identity
Share the same unknowns
Mechanism
Solved together for values that satisfy every equation at once
Resolved
"At once" is the discriminating condition
